Model per phase

Each evaluation phase runs on its own model (the current pipeline uses a cheap, recall-first model for Inclusion and a stronger model for Exclusion). Pick a model per phase; leave as "Use active model" to fall back to the selected active model.

Mode — Synchronous makes one API call per page (current behaviour). Batch submits the phase as one asynchronous Anthropic Message Batches job (~50% cheaper). Batch needs an Anthropic model — DeepSeek has no batch API, so a DeepSeek phase always runs synchronously.
