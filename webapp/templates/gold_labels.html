Gold labels{% if wizard %} · one page at a time{% endif %}

Rate what the pipeline did with each page in one run: correct / wrong / borderline, with a one-line reason. Each verdict is stored as a gold label (correct keep → in, correct drop → out, wrong keep → out, wrong drop → in) that the benchmark scores every model and run against. You don't need every page: set a target per stage below and the page picks that many at random (a fixed, seeded pick, so it is the same set every time and raising a target only adds pages). The sampling fraction is stored with each label so the benchmark can weight it. Labels are per page, not per run, so they carry over to every run.
